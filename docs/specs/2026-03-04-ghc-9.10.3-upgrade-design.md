# GHC 9.10.3 Upgrade Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Upgrade GHC from 9.6.7 to 9.10.3 to match the eventium library.

**Architecture:** Minimal version bump with dependency audit. Change compiler references in nix/cabal/CI, bump template-haskell bounds, audit cabal.project workarounds, then build and fix.

**Tech Stack:** GHC 9.10.3, Cabal, Nix flakes, GitHub Actions CI

---

### Task 1: Update Nix flake GHC version

**Files:**
- Modify: `flake.nix:14-15`

**Step 1: Change GHC package set**

In `flake.nix`, change line 14-15 from:
```nix
        # Use GHC 9.6.7 as specified in requirements
        hPkgs = pkgs.haskell.packages.ghc967;
```
to:
```nix
        # Use GHC 9.10.3 to match eventium
        hPkgs = pkgs.haskell.packages.ghc9103;
```

**Step 2: Refresh flake.lock**

Run: `nix flake update`
Expected: flake.lock updated with new nixpkgs snapshot

**Step 3: Verify nix dev shell enters**

Run: `nix develop --command ghc --version`
Expected: Output includes `9.10.3`

Note: If `ghc9103` is not available in the nixpkgs snapshot, try `ghc910`. Check available GHC versions with:
```bash
nix eval nixpkgs#haskell.packages --apply 'ps: builtins.filter (n: builtins.match "ghc9.*" n != null) (builtins.attrNames ps)'
```

### Task 2: Update cabal.project compiler and audit workarounds

**Files:**
- Modify: `cabal.project:9,11-14`

**Step 1: Update compiler version**

Change line 9 from:
```
with-compiler: ghc-9.6.7
```
to:
```
with-compiler: ghc-9.10.3
```

**Step 2: Try removing entropy allow-newer**

Lines 11-14 currently read:
```
-- Fix HLS dependency resolution issues
-- Allow newer Cabal versions for setup dependencies in entropy package
-- This resolves the conflict between entropy:setup.Cabal bounds and GHC 9.6.7
allow-newer: entropy:Cabal
```

Remove these 4 lines (comment + directive). If the build in Task 4 fails with an entropy Cabal bound error, re-add `allow-newer: entropy:Cabal`.

**Step 3: Keep hashable constraint**

Leave `constraints: hashable >= 1.4.0.0 && < 1.5` as-is. The uuid/hashable incompatibility is independent of GHC version.

---

### Task 3: Update package.yaml template-haskell bound

**Files:**
- Modify: `package.yaml:62`

**Step 1: Bump template-haskell upper bound**

Change line 62 from:
```yaml
  - template-haskell >= 2.16 && < 2.22
```
to:
```yaml
  - template-haskell >= 2.16 && < 2.23
```

GHC 9.10.3 ships template-haskell 2.22.x. The old bound `< 2.22` excludes it.

### Task 4: Build and fix compilation errors

**Step 1: Clean and build**

Run (inside `nix develop`):
```bash
cabal clean && just build
```

Expected: Successful build, or compilation errors to fix.

**Step 2: If entropy allow-newer removal broke the build**

If you see an error like:
```
Rejected: entropy:setup.Cabal-...
```

Re-add to `cabal.project`:
```
allow-newer: entropy:Cabal
```

Then rebuild.

**Step 3: Fix any new GHC warnings or errors**

GHC 9.10 may introduce new warnings. Fix them as they appear. Common changes:
- New redundant constraint warnings
- Stricter incomplete pattern warnings
- Changes in type inference edge cases

**Step 4: Run tests**

Run: `just test`
Expected: All tests pass.

**Step 5: Run format and lint**

Run: `just check`
Expected: No formatting or lint issues. If ormolu/hlint versions changed, there may be new suggestions — fix them.

**Step 6: Commit**

```bash
git add flake.nix flake.lock cabal.project package.yaml
git commit -m "chore: upgrade GHC from 9.6.7 to 9.10.3"
```

Include any source files that needed fixes for compilation.
