# Banking Configuration — Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add persisted, encrypted, per-user **bank connections** (monobank) to the Configuration aggregate, expose connection CRUD + a live "list external accounts" call + an explicit `externalId → local account` mapping, and route a connection-scoped resync through the stored token — all behind the existing global banking feature flag.

**Architecture:** Event-sourced Configuration aggregate (Eventium). New domain events fold into `BankingConfiguration.connections`. The monobank API **token is encrypted (AES-256-GCM) in the service layer** so only ciphertext enters the event log; a new `Infrastructure.Crypto.SecretBox` module wraps cryptonite. Within-aggregate invariants live in the pure `CommandHandler`; cross-aggregate checks (account exists/owned, account already mapped by another connection) live in `ConfigurationService` (which has read-model access). Resync routes monobank accounts to local accounts via the connection's explicit `accountMap`, replacing the old exact-IBAN `buildBankLink`.

**Tech Stack:** GHC 9.10, Servant, Eventium (event sourcing), `cryptonite` (AES-256-GCM), Aeson, hspec + hspec-wai.

**Spec:** `../../../monorepo/docs/specs/2026-06-07-banking-configuration-design.md` (web repo). This plan implements §2 (backend); the web plan implements §3.

## Error-handling hop (read before Tasks 5–9)

There are **two** `ConfigurationError` types — do not conflate them:
1. the **handler-local** one in `src/Domain/Configuration/CommandHandler.hs:57` (pure aggregate rejections), and
2. the **public** `DomainError` surface in `src/Domain/Core/Errors.hs`.

`Web/ErrorMapping.hs` maps **`DomainError`**, not the handler-local error. A new aggregate rejection reaches a specific HTTP status only via a **three-part hop**:
- (a) add the constructor to the **handler-local** `ConfigurationError` (CommandHandler.hs);
- (b) add a matching `DomainError` constructor (`Domain/Core/Errors.hs`) **and** a clause in `translateConfigurationError` (`ConfigurationService.hs:315`) — otherwise `defaultTranslateConfigurationError` (`:326`) collapses it to a generic `ConfigurationError Text` → **HTTP 400**, losing the intended code/status;
- (c) add the `mapDomainError` clause (`Web/ErrorMapping.hs`) for the new `DomainError`.
Tasks below call out (a)/(b)/(c) explicitly.

```haskell
{-# LANGUAGE OverloadedRecordDot #-}
module Infrastructure.Crypto.SecretBox
  ( EncryptedSecret (..)
  , KeyRing
  , mkKeyRing
  , CryptoError (..)
  , encryptSecret
  , decryptSecret
  ) where

import Crypto.Cipher.AES (AES256)
import Crypto.Cipher.Types (AEADMode (AEAD_GCM), BlockCipher (..), Cipher (..), AuthTag (..), aeadSimpleEncrypt, aeadSimpleDecrypt)
import Crypto.Error (CryptoFailable (..))
import Crypto.Random (getRandomBytes)
import Data.ByteArray (convert)
import qualified Data.ByteString as BS
import qualified Data.ByteString.Base64 as B64
import qualified Data.Map.Strict as Map
import Data.Text (Text)
import qualified Data.Text.Encoding as TE
import GHC.Generics (Generic)
import Data.Aeson (FromJSON, ToJSON)

data EncryptedSecret = EncryptedSecret
  { keyVersion :: !Int
  , nonce      :: !Text   -- base64
  , ciphertext :: !Text   -- base64
  , authTag    :: !Text   -- base64
  } deriving (Show, Eq, Generic)
instance ToJSON EncryptedSecret
instance FromJSON EncryptedSecret

data KeyRing = KeyRing { current :: !Int, keys :: !(Map.Map Int BS.ByteString) }

-- | Build a key ring. Keys must be exactly 32 bytes (AES-256).
mkKeyRing :: Int -> [(Int, BS.ByteString)] -> KeyRing
mkKeyRing cur ks = KeyRing cur (Map.fromList ks)

data CryptoError = KeyNotFound Int | BadKeyLength | DecryptFailed | BadEncoding Text
  deriving (Show, Eq)

tagLen :: Int
tagLen = 16

encryptSecret :: KeyRing -> Text -> IO EncryptedSecret
encryptSecret ring plain = do
  iv <- getRandomBytes 12 :: IO BS.ByteString
  let key = Map.findWithDefault BS.empty ring.current ring.keys
  case initGcm key iv of
    Left e  -> error ("SecretBox.encryptSecret: " <> show e) -- key is config-validated at startup
    Right aead -> do
      let (AuthTag tag, ct) = aeadSimpleEncrypt aead BS.empty (TE.encodeUtf8 plain) tagLen
      pure EncryptedSecret
        { keyVersion = ring.current
        , nonce      = b64 iv
        , ciphertext = b64 ct
        , authTag    = b64 (convert tag)
        }

decryptSecret :: KeyRing -> EncryptedSecret -> Either CryptoError Text
decryptSecret ring enc = do
  key <- maybe (Left (KeyNotFound enc.keyVersion)) Right (Map.lookup enc.keyVersion ring.keys)
  iv  <- unb64 enc.nonce
  ct  <- unb64 enc.ciphertext
  tag <- unb64 enc.authTag
  aead <- either (const (Left BadKeyLength)) Right (initGcm key iv)
  case aeadSimpleDecrypt aead BS.empty ct (AuthTag (convert tag)) of
    Nothing -> Left DecryptFailed
    Just pt -> Right (TE.decodeUtf8 pt)

-- helpers
initGcm :: BS.ByteString -> BS.ByteString -> Either String _   -- AEAD AES256
initGcm key iv = case (cipherInit key :: CryptoFailable AES256) of
  CryptoFailed e -> Left (show e)
  CryptoPassed c -> case aeadInit AEAD_GCM c iv of
    CryptoFailed e -> Left (show e)
    CryptoPassed a -> Right a

b64 :: BS.ByteString -> Text
b64 = TE.decodeUtf8 . B64.encode

unb64 :: Text -> Either CryptoError BS.ByteString
unb64 t = either (Left . BadEncoding . (<> " ") . const t) Right (B64.decode (TE.encodeUtf8 t))
```

> Note for implementer: the exact AEAD type signature (`aeadInit`/`aeadSimpleEncrypt`) comes from `Crypto.Cipher.Types`; adjust the `initGcm` return type to the concrete `AEAD AES256`. Verify the cryptonite version exports `aeadSimpleEncrypt`/`aeadSimpleDecrypt` (it does in 0.29–0.30). `base64-bytestring` and `cryptonite` are already project dependencies.

## Risks & notes for the implementer

- **cryptonite AEAD specifics** (Task 1): get the exact `AEAD AES256` type/`aeadInit` signature right; this is the one place to verify against the installed cryptonite version before building out.
- **Provider seam first** (Task 2b): there is no existing HTTP-layer provider stub — Tasks 8/9 depend on the seam + `mkAppBankingEnabledSeeded` built in Task 2b. Don't start 7–9 until 2b is green.
- **Error hop** (Tasks 5/6/7): three parts — handler-local `ConfigurationError` (a), `DomainError` + `translateConfigurationError` (b), `ErrorMapping` (c). Skipping (b) silently downgrades every new error to HTTP 400.
- **Cross-aggregate validation** (Task 6): account ownership/role is in the account read model, not the Configuration aggregate — do it in the service, before the command. Don't try to push it into the pure handler.
- **`copyBanking` clone-on-write** must carry `connections` or the first post-seed mutation silently drops them.
- **Test key ring**: `createTestAppEnv` / `mkAppBankingEnabledSeeded` must provide a deterministic 32-byte key so encryption is reproducible in tests.
- **Currency numeric→alpha** (Task 8): reuse the existing converter the import path already uses; don't hand-roll a new table.
- **`maskedPan` is always empty** for monobank today (`cardMasks = []`, `Monobank.hs:141`) — `Maybe Text` handles it; the picker just won't show a PAN.
- **No migration**: the header resync has no runtime callers (spec §2.5) — only `BankingAPISpec` and `test-banking.sh`, both updated here.
